South African Electricity Demand Forecast
   1. Problem Statement: South Africa needs to anticipate electricity demand to support electricity generation, grid management and energy planning.
   2. Project Objective: To develop a machine-learning  model that predicts future national electricity demand using historical electricity data and relevant external factors.
   Machine-learning: Supervised learning-regression
   Target Variable: Electricity demand, measured in megawatt-hours (MWh)
   3. Technologies and infrastructure: 
        Google Cloud Platform:  Cloud infrastructure.
        GoogleBigQuery: Cloud data storage and analysis.
        SQL: Data quering, filtering, transformation.
        APIs: Retrieve external data, such as weather information.
        Python: Main programming language.
        NumPy: Numerical computation.
        Pandas: Data manipulation and analysis.
        Scikit-learn: Machine learning model development and evaluation.
        Git and Github: version control and project management.
